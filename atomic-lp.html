Atomic LP Scanner

Record album discovery, metadata, release research, and collection workflow.

Atomic LP is a full-stack web application for identifying and researching vinyl records using barcode, catalog number, artist, and album searches. It combines information from multiple music-data services to help resolve album identities, compare vinyl releases and pressings, review marketplace information, and save likely matches.

Try the Live App

PROJECT OVERVIEW

How It Works

A search begins with a barcode, catalog number, or artist and album. Atomic LP coordinates multiple external data services to identify the album, resolve the appropriate vinyl release family, and present release details that can be compared and filtered. The application also maintains persistent user data and supports workflows for saving likely matches and returning to them later.

The backend is built with Python and Flask, with PostgreSQL and SQLAlchemy for persistence. The browser interface uses JavaScript, HTML, and CSS. Development has included entity matching, API orchestration, caching, provider rate-limit handling, performance instrumentation, error recovery, automated regression testing, and responsive browser workflows.

Key Tools: Python, Flask, JavaScript, PostgreSQL, SQLAlchemy, REST APIs, JSON, Discogs, MusicBrainz, OAuth, pytest, Gunicorn, Render.
