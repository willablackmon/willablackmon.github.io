## Featured Project

### Atomic LP Scanner

Atomic LP Scanner is a full-stack web application for identifying and researching vinyl records from barcode, catalog number, artist, and album searches. The portfolio includes a dedicated project page with a richer overview, engineering details, and walkthroughs.

- **Project page:** `atomic-lp.html`
- **Live application:** https://lp-scanner.onrender.com/
