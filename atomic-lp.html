Atomic LP Scanner

Vinyl album identification, release research, marketplace, and collection workflow.

Atomic LP Scanner is a full-stack web application built to make the process of identifying a physical record and narrowing it to the most useful vinyl release information faster. A search can start from a barcode, catalog number, artist, album, or a combination of those inputs.

Try the Live App

PROJECT OVERVIEW

From Record in Hand to Release Candidates

Vinyl research often begins with incomplete or inconsistent clues: a barcode, a catalog number, an artist and title, or a record whose packaging does not uniquely identify a pressing. Atomic LP coordinates multiple music-data services to resolve the album identity, surface plausible matches, and organize the resulting vinyl-release information into a single browser workflow.

Clear searches can continue directly into release research. When more than one album identity is plausible, the application presents Possible Matches so the user can choose the correct album before deeper release work begins. The resulting workflow brings together artwork, release metadata, marketplace information, external album resources, and user-selected records without requiring the user to repeat the same search across multiple sites.

CAPABILITIES

What the Application Does

Flexible Record Search

Search by barcode, catalog ID, artist + album, artist only, or album only, with browser-based scan/upload workflows for record identification.

Possible Match Resolution

Ambiguous results are presented as candidate albums with supporting metadata so a user can select the best match instead of accepting a weak automatic guess.

Vinyl Release Research

Resolve an album to its vinyl release family, compare available pressings, inspect release details, and filter out formats that are outside the LP workflow.

Marketplace & External Resources

Bring marketplace information and supporting album links into the same research workflow, including artwork and links to additional music and shopping resources when available.

Discogs Collection & WantList

Users can connect a Discogs account and search or compare results against their own Collection and WantList without mixing personal library data into the public search workflow.

Save & Export

Keep selected releases in a session list or persistent user library and export saved release information for later research and comparison.

SECURITY & CONNECTED ACCOUNTS

Personal Discogs Integration

Public album research does not require access to a user's personal Discogs data. Collection and WantList features are enabled separately through OAuth authorization. Connected-account tokens are stored encrypted on the server and are not exposed in browser code.

This separation allows Atomic LP to use public music metadata for general discovery while adding personalized Collection and WantList workflows only for users who explicitly connect an account.

ENGINEERING

Built as a Stateful Multi-Service Workflow

The backend is built with Python and Flask, with PostgreSQL and SQLAlchemy for persistence. The browser interface uses JavaScript, HTML, and CSS. The application coordinates several external data services while managing provider limits, partial results, slow responses, and alternate discovery paths.

Development has focused on identity matching, API orchestration, caching, rate-limit awareness, cancellation and stale-result protection, performance instrumentation, responsive mobile behavior, error recovery, and automated regression testing. New searches, STOP, and CLEAR ALL supersede work from prior searches so late responses cannot overwrite the current record.

Key Tools: Python, Flask, JavaScript, PostgreSQL, SQLAlchemy, REST APIs, JSON, Discogs, MusicBrainz, OAuth, pytest, Gunicorn, Render.
