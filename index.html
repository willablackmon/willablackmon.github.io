CURRENT APPLICATION · 2026–PRESENT

AtomicLP Listen

Working Web App · Active Development

The Cure · Neon visualizer · click to enlarge ↗

Browser-based song recognition paired with interactive, album-aware music visualizations.

AtomicLP Listen captures a short microphone sample in the browser and uses a Python/Flask backend with ShazamIO to recognize the recording. It presents the artist, track, album, artwork, and release context, then brings the album to life with real-time visualizations and configurable effects.

The interface includes spectrum, waveform, oscilloscope, and wave-ribbon views, plus controls for color, responsiveness, background artwork, and visual intensity. Automatic listening and a responsive interface support a continuous music-discovery experience.

Key Tools: Python, Flask, JavaScript, Browser Media APIs, ShazamIO, JSON, pytest, Gunicorn, Nginx, Ubuntu Server, GitHub Actions, Cloudflare Tunnel.
